ZOYAS.VISUALS — gotowy pakiet do Cloudflare Pages

Zawartość: index.html, regulamin.html, polityka-prywatnosci.html, assets/ (style, obrazy, filmy demonstracyjne z watermarkiem).

Uwaga: teksty hero/marketingowe i układ są wersją roboczą — nie odnaleziono pełnej treści wszystkich wcześniej zatwierdzonych bloków. W razie potrzeby podmień je przed publikacją.

Formularz opinii otwiera program pocztowy użytkownika (mailto), nie zapisuje niczego w bazie. Opinie trzeba publikować ręcznie po zgodzie autora. Karta Monika jest wyraźnie oznaczona jako przykład, a nie prawdziwa opinia.

Do publikacji: wypakuj ZIP i prześlij zawartość do repozytorium GitHub z zachowaniem struktury katalogów (albo użyj direct upload w odpowiednio skonfigurowanym projekcie). GitHub-connected Cloudflare Pages wdroży commit automatycznie.

Ważne: przed publikacją zweryfikuj treść dokumentów prawnych z polskim prawnikiem. Sprawdź, czy możesz publicznie pokazywać wizerunki dzieci na zdjęciach i filmach.
